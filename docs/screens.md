# 화면 명세 (스토어 스크린샷 기준)

- **근거**: `docs/store/01.jpg`~`12.jpg`, `11.png`. "CNC Master CALC" 스토어 스크린샷 12장과 장마다 낸 분석이다. 애매한 곳은 원본을 다시 열거나 잘라서 확인했다.
- **표기**
  - **확인**: 사진에 직접 보인다.
  - **추정**: 사진으로 짐작한 것이다.
  - **확인 안 됨**: 사진에 없다. 우리가 정한다.
- **치수**: 폰 사진 폭 1440px 을 411dp 로 보고 1dp ≈ 3.5px 로 환산했다. 전부 추정값이다.
- **색**: JPEG 에서 뽑은 hex 라 오차가 있다. 1.1 의 "색 주의"를 먼저 읽는다.

### 1.2 글자 위계

- **글꼴 (추정)**: 산세리프는 한글·라틴 모두 Noto Sans KR(Source Han Sans) 계열이다.
- **고정폭 (확인)**: 두 종류가 섞여 있다.
  - **세리프 고정폭** (Courier 계열, 자간 넓음): 아래에 쓴다.
    - 시뮬 S/F 큰 값, POSITION·측정점·보정좌표 숫자, REAL TIME

### 1.5 숫자 입력 방식

**전용 키패드**

- **우리가 정할 것**: 계산기 숫자칸에 쓸 키보드.

**값 표기 (확인)**
- 결과는 소수 셋째 자리다. 예: 34.000 · -2.186 · -29.234 · 32.979 · -36.951

**자리표시와 기본값**
- **확인**: 03 직경칸 자리표시가 범위와 단위를 알린다: "∅0.8 ~ 20.0 mm (0.1mm 단위)".
- **추정**: 범위 검사가 있다.
- **확인**: 12 의 회전 0 만 회색이다.
- **추정**: 회전 0 은 자리표시이거나 기본값 표시다.
- **확인 안 됨**: 잘못된 값을 넣었을 때 경고를 어떻게 보여 주는지. 사진에 오류 표시가 한 번도 없다.

**형상 그림 공통 규칙 (확인)**
- 꺾은선은 3구간(직선 – 45° 경사 – 직선)이다. 경사 양 끝에 T 점을 둔다.
  - T 점은 지름 약 6dp 원이다. 채움은 카드 바탕색, 테두리는 빨강이다.
  - **T1 = 오른쪽 점, T2 = 왼쪽 점**이다.
- 기준 점선은 T1 에서 왼쪽으로 뻗은 수평 빨강 점선이다(대시 약 4dp / 간격 3dp).
- 각도 표시
