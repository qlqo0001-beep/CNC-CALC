## 1. 요청과 반영

| 요청 | 반영 |
|---|---|
| 그림을 세련되게, 쓰기 편하게, 다른 앱 참고(10-17) | 다른 계산기 앱, 사용자 불만, 현장용 앱 지침을 조사했다(출처 110개). 화면마다 점검해 고칠 것 126건을 찾고 묶음별로 고쳤다(아래 3절) |
| 헤더·메뉴(결정 C8·C9) | 모든 화면 '← 뒤로 · 제목 · 메뉴 · ? 도움말'. 테마는 메뉴 안 '자동·밝게·어둡게'. 쓸 수 있는 계산을 먼저, 준비 중 4개는 아래 묶음에 둔다 |
| 보정 방식(E21·E20) | 앱 전체에 스위치 하나 '기계 보정(G41/G42) / 직접 보정(G40)' — 테이퍼·라운드 함께, 기억, 기본 기계 보정. 직접 보정 NC 첫 줄 `(G40 DIRECT R0.4 T3)` |
| 테이퍼 입력 묶음(E19) | '도면 치수'(점마다 X·Z·모서리 R 한 줄, 각도, 시작·끝)와 '공구'(노즈 R, Z 여유, 팁) |
| 기본값 0 | 도면 치수와 Z 여유·X 여유는 모두 0 에서 시작한다(공구 값은 그대로). 값이 모자라면 빨간 오류 대신 파란 안내 |
| 숫자칸(10-17 답, 현장 "클릭시 숫자가 초기화 되지 않음") | 칸을 누르면 기존 값이 골라진 채 보이고, 첫 키가 덮어쓴다. 누를 때마다 결과·그림·NC 가 바로 바뀌고 확인 단추는 없다. 아무것도 안 치고 닫으면 원래 값이 남는다. '다음' 으로 다음 칸 |
| 현장 "Z 여유를 바꿔도 G0 에 반영 안 됨" | 진입은 늘 첫 깎는 점에서 Z 로 max(Z 여유, 노즈 R). 모든 형상·정/역·2중·홈 X 여유·두 NC 를 쓸어 보는 시험으로 고정(`entryFollowsZClearance` 등). Z 여유가 노즈 R 보다 작으면 칸 아래 안내 |
| 현장 "끝점은 직접 넣을 때만" | 끝점을 비우면 마지막 점(모서리 R 이면 그 끝)에서 끝나고, 그 값을 자동값으로 보인다. 시작점도 같은 원칙(비우면 '안 깎음') |
| 홈 기준·용어(10-17 답) | 홈 기준 인선 기본 왼쪽(팁 3), 홈 NC 는 직접 보정 하나. '주 R / 모서리 R' 그대로 |
| 라운드 모서리 R 빈칸(G11) | 빈칸 = 0(날카로운 꼭짓점), 테이퍼와 같다 |
| 내경 라운드 + 보링바 간섭(D1~D9) | 내경 형상 2~6 + 3점호, 막힘 기본 + 관통 스위치, 노란 띠 + 빨간 표시, 뒤보링 포함. 묻고 답한 표는 `stage2-report.md` 8.1 |
| 승인하지 않은 것 | 공구 값 기억·노즈 R 공유(C10), 지우기+되돌리기(E22), 삼각형 셋째 값 자동 정리(H8) |

## 2. 계산 엔진에서 바뀐 것

모두 사용자가 승인했거나, 점검에서 결함으로 확인된 것이다. 하나마다 calc 시험을 더했다.

- **테이퍼**
  - Z 여유 0 을 허용한다(노즈 R·Z 여유 둘 다 0 이면 `BAD_INPUT`).
  - 진입은 Z 로 max(Z 여유, r)이다.
  - 끝점을 비우면 마지막 점에서 끝나고, 후퇴 규칙도 그에 맞췄다.
  - `NOSE_GT_SLOPE` 는 짧은 경사의 한 끝이 오목할 때만 띄운다. 볼록-볼록 면취의 헛경고를 없앴다.
- **라운드**: 진입 max(Z 여유, r). 내경 형상 2~6 을 넣었고, NC 줄과 요소를 잇는 `ncRefs`/`lineOf` 를 더했다.
- **Fmt**: 90° 를 0.09° 미만으로 넘는 원호(CAD 넷째 자리로 넣은 1/4 원)는 R 블록 하나로 쓴다.
- **보링바 간섭(`Holder.kt`)**
  - 인서트·바·공구대·최소 가공경을 보고, 뒤보링도 포함한다.
  - 다른 방법(조밀 표본)으로 따로 검증하는 시험을 두었다(`HolderVerifyTest`).
- **직각삼각형**: 다른 계산기처럼 10 000 mm 한도를 둔다. 아주 큰 값에서 틀린 숫자가 경고 없이 나오던 것을 막았다.

## 3. 화면에서 달라진 것

- **그림**
  - 테이퍼·홈·라운드·삼각형 그림을 한 규칙(`DrawKit`)으로 다시 그렸다: 소재 빗금, 회전축 중심선, 굵은 윤곽과 가는 치수선, 화살표 치수.
  - 바이트와 보링바를 알아볼 수 있게 그렸다(뒤보링은 인서트만 뒤집고 바는 입구 쪽).
  - 이송 방향 화살표와 시작·끝 표시를 넣었다.
- **형상 뷰어**
  - 한 손가락·휠은 페이지를 스크롤한다(그림이 잡지 않음).
  - −/+/맞춤 단추, 크게 보기를 넣었다.
  - 라벨은 알약 모양이고 겹치지 않게 자리를 고른다.
  - 내경은 지름 전체 단면, 보링바 윤곽, 간섭 빨간 칠과 NC 줄 번호를 보인다.
- **키패드**: 1절의 덮어쓰기·즉시 반영·'다음'. 키패드 안 작은 그림에 지금 고치는 치수를 짚고, 결과 한 줄도 보인다.
- **결과·NC**
  - 계산이 멈추면 이유를 위쪽과 해당 칸(빨간 테)에 보인다.
  - 값이 서로 안 맞으면 '… 비우고 계산' 단추로 한 번에 고친다.
  - NC 카드는 줄 번호와 이름 붙은 큰 복사 단추를 갖췄다. 아래쪽 결과 띠가 요약을 계속 보인다.
- **앱 틀**: 누르는 자리 48dp 이상, 묶음 도움말 시트, 준비 중 화면 안내. PC 창은 본문 640dp 가운데에 두고 창 크기·자리를 기억한다.
- **글**
  - 고정폭 글꼴을 JetBrains Mono 로 바꿨다(0 과 O, − 가 또렷).
  - 한글은 어절 단위로 줄을 바꾼다.
  - 작은 글은 대비 4.5:1 이상이다(메뉴 단추 포함).

## 4. 확인한 방법

- **계산**: 손 계산·외부 기준값(2단계)에 더해, 3단계에서 바뀐 규칙마다 시험을 넣었다. 내경·간섭은 시험을 먼저 쓰고 구현한 뒤, 표본 검증과 대조했다.
- **화면 숫자**: `UiGoldenTest` 가 모든 시험 화면의 좌표와 NC 를 고정한다. 바꿀 때는 `-DupdateGolden=true` 로, 바뀐 줄을 커밋에 적었다.
- **화면 모양**
  - 시험 화면을 모두 라이트·다크와 큰 글꼴·좁은 폰·넓은 PC 로 찍었다.
  - 두 차례 나눠 살폈고, 나온 문제는 따로 반박 검증한 뒤 고쳤다.
  - 1차는 재설계 전으로, 42건을 확인했다.
  - 2차는 재설계 뒤로, 확인된 것을 고쳤다. 360dp 에서 헤더 제목이 줄어들다 '…' 로 끝나는 한 건만 설계대로라 그대로 두었다.
- **실제 조작**: 만든 PC 앱을 가상 화면에서 실제 마우스·키보드로 눌러 봤다(`stage2-report.md` 6.2). 키패드, 복사, 뒤로, Ctrl+휠, 창 크기 기억을 확인했다.

## 5. 남은 것 (사람이 확인할 것)

- **가공에 영향**: `stage2-report.md` 6절 1~5(FANUC 보정 시작 블록, G41/G42 끝 블록, 역방향 해석, 라운드 치수 해석, 홈 관례)는 그대로다.
- **내경·보링바**: `stage2-report.md` 8.3
  - 단면 검사는 둥근 바 자루만 정확하다.
  - 진입·후퇴 길은 보지 않는다.
  - 프리셋은 카탈로그 값이고, 날 길이는 품번 숫자다.
- **홈 X 여유 0**: 사용자 결정으로 0 이 기본이라 G00 이 외경(ØD)까지 바로 온다. 현장에서 쓰는 여유를 넣어 쓸 것.
- **실제 폰·Windows**(`stage2-report.md` 6.2 후속): 내비 막대, 글꼴 최대, 장갑, 두 손가락 확대, 안드로이드 클립보드, exe 창 자리.
- **글**: 숫자·기호와 뒤 글 사이 줄바꿈('±10000 mm' 등). 3점호 고르기 카드 설명이 글꼴 130% 에서 잘린다(6.1 후속 2·4).

## 6. PC 에서 할 일

1. `D:\bmt-nosecalc` 에서 `git pull`(가지 `ninesik/beautiful-shannon-i2e1tl`).
2. `gw.bat :calc:jvmTest :shared:jvmTest :androidApp:assembleRelease :desktopApp:createDistributable`
3. 릴리스 APK 는 `D:\android-sdk\keys` 키로 서명돼 회사 폰에 덮어 설치할 수 있다. 클라우드에서 만든 APK 는 서명이 달라 덮어 설치되지 않는다.
4. PC 바로가기 'BMT 노즈R 계산기 (PC)' 는 `desktopApp\build\compose\binaries\main\app\BMT-NoseR\BMT-NoseR.exe` 를 가리키면 새로 만든 판이 열린다.
